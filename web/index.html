Bélády's Anomaly Visual Verification

Bélády's anomaly is the counter-intuitive phenomenon where increasing the number of page frames results in more page faults for FIFO, whereas Stack Algorithms (LRU, Optimal) are mathematically proven to be immune.

Analyzed Reference Sequence: 1, 2, 3, 4, 1, 2, 5, 1, 2, 3, 4, 5

Anomaly Confirmed: FIFO 3 Frames vs 4 Frames

When frames increase from 3 frames to 4 frames, FIFO page faults INCREASE from 9 to 10 faults (+1 fault). Meanwhile, LRU faults strictly drop from 10 to 8 faults, verifying the Stack Inclusion Property ($S_m \subseteq S_{m+1}$).

Multi-Algorithm Benchmark Suite

Side-by-side performance comparison of all 6 algorithms evaluated under a 100-reference Locality of Reference (80/20) workload with 4 physical frames.

Least Recently Used (LRU) O(1) Time · O(F) Space

Evicts the page that has not been referenced for the longest time period. Exploits temporal locality. Implemented in our C++ core using a custom Doubly Linked List + Hash Map to guarantee strict $O(1)$ page promotion and victim eviction.

// C++ O(1) LRU Page Hit auto* node = it->second; orderList.move_to_front(node); // O(1) relink FrameNumber frame = node->data.frame; // O(1) LRU Victim Eviction auto* victimNode = orderList.getTail(); // O(1) LRU orderList.pop_back(); pageMap.erase(victim.page);
  • Near optimal hit rates
  • Stack algorithm (No Belady's anomaly)
  • Requires hardware / pointer overhead

Optimal (Bélády's OPT/MIN) O(N·F) Time · O(F) Space

Replaces the page that will not be used for the longest period of time in the future. Serves as the theoretical benchmark against which all online algorithms are measured. Impossible to implement in a real OS without future lookahead.

// C++ Optimal Forward Lookahead for (auto candidate : residentPages) { size_t nextUse = findNextUse(candidate, currIdx + 1); if (nextUse > farthestIndex) { farthestIndex = nextUse; victim = candidate; } }
  • Theoretical minimum page faults
  • Guaranteed benchmark baseline
  • Cannot be implemented in real-time OS

First-In, First-Out (FIFO) O(1) Time · O(F) Space

Replaces the page that has resided in physical memory the longest, regardless of how frequently or recently it was accessed. Simple queue implementation, but suffers from Bélády's Anomaly where more memory causes more page faults.

// C++ FIFO Eviction auto* victimNode = orderList.getHead(); // Earliest arrived orderList.pop_front(); pageMap.erase(victim.page); // New page inserted at back orderList.push_back({newPage, frame});
  • Low computational overhead
  • Simple queue structure
  • Prone to Bélády's anomaly
  • May evict frequently used pages

Least Frequently Used (LFU) O(1) Time · O(F) Space

Replaces the page with the lowest reference count. Our C++ engine implements LFU using Frequency Buckets (hash map of doubly linked lists) to maintain true $O(1)$ operations with deterministic LRU tie-breaking.

// C++ O(1) LFU Promotion freqBuckets[oldFreq].remove(oldNode); entry.freq = oldFreq + 1; PageNode newNode = freqBuckets[entry.freq].push_front(entry); pageMap[page] = newNode;
  • Excellent for repetitive frequency loops
  • O(1) frequency bucket design
  • Past frequency can cause cache pollution

Clock (Second Chance) O(1) Amortized · O(F) Space

Hardware-efficient approximation of LRU. Uses a circular buffer of frame slots and a sweeping "clock hand". Frames have a reference bit set on hit; the clock hand clears the bit (giving a second chance) or evicts on bit 0.

// C++ Clock Sweep while (true) { if (clockBuffer[hand].referenceBit) { clockBuffer[hand].referenceBit = false; // 2nd chance hand = (hand + 1) % frameCount; } else { victim = clockBuffer[hand].page; // Victim found! break; } }
  • Very close to LRU performance
  • Low hardware/CPU overhead
  • May degenerate to FIFO in worst case

Most Frequently Used (MFU) O(F) Time · O(F) Space

Replaces the page with the highest frequency count based on the premise that pages with low counts have just been loaded and will be needed soon. Used in specialized streaming architectures.

// C++ MFU Selection for (const auto& entry : residentMap) { if (entry.freq > maxFreq) { maxFreq = entry.freq; victim = entry.page; } }
  • Protects recently loaded pages
  • Specialized workload optimization
  • Suboptimal for standard temporal locality
